## 成本公式

单条完整成本 = 服务器月费 / 当月成功处理数 + 额外存储费用 + 额外下行流量费用 + Agent实际调用费用 + 外部ASR费用（如启用） + 重试/失败任务摊销。

固定服务器CPU转录不另加一笔小时计算费，已包含在月费中；若采用按时计费工作机，则用小时价格乘真实处理时间，替代相应固定算力摊销。本地磁盘套餐内空间不额外收对象存储费。带宽套餐内流量不再加按量下行费用。排队等待不是额外CPU计费时间。

当前使用CLI额度，不具备逐条人民币账单；AuraBaba价格未知，必须由实际调用/token/套餐报价代入。长内容可能分段调用，不能按一条视频等于一次Agent请求估算。重试、连接测试也可能产生调用费用。

## 可复算示例：全部是预算假设，不是厂商报价

假设服务器100元/月；媒体与转录保留7天；每条含ZIP和缓存的额外存储0.25GB；用户一次下载0.12GB；对象存储0.12元/GB/月；额外下行0.50元/GB；Agent每条合计0.50元；本机ASR无外部服务费。

额外存储 = 0.25 × 0.12 × 7/30 = 0.007元。
下行 = 0.12 × 0.50 = 0.060元。
模型 = 0.500元。
100条/月：100/100 + 0.007 + 0.060 + 0.500 = 1.567元/条。
1000条/月：100/1000 + 0.007 + 0.060 + 0.500 = 0.667元/条。
1000条是成本情景，不代表2核4GB能处理该数量。

若把Agent假设改成0.10–2.00元，同样小文件与一次下载下，100条/月约1.17–3.07元/条，1000条/月约0.27–2.17元/条。尚未包含失败重试和税费，不能当作实际成本报价。

高码率场景：存储2GB保留7天、每条下载1GB，在相同假设单价下存储0.056元、下行0.50元；100条/月加0.50元Agent时总计2.056元。每次重复下载增加下行费用；保留更久增加存储。当前素材包、原视频、识别音频、共享缓存可能重复占空间，未实施自动过期清理。

## 飞书配置体验与条件

当前方案：平台管理员配置自己的企业自建应用。后台输入App ID、App Secret、目标文件夹；保存先验证Token，再点击飞书测试，检查创建、正文、图片与读取。Secret不回显。需要有效应用版本、云文档创建/读写、素材上传对应权限；目标文件夹须允许应用访问。凭据错误、缺权限和文件夹访问失败会在后台反馈。

普通用户无需创建应用、填写Secret；目前保存位置仍是平台配置的空间。链接默认不自动公开，需用真实目标用户账号确认可打开、可编辑；不可把“创建成功”称为“用户体验已全部验证”。

如果需求是保存到用户自己飞书：需补OAuth登录、授权回调、用户Token刷新、每用户目标位置与任务隔离；目前尚未实现。禁止每位普通用户改全站App Secret。确认产品选择后再实现相应授权与分享流程。

## 当前后台限制

并发1–4、排队0–100、视频1–240分钟、媒体50–3072MiB、最低磁盘1–100GiB、暂停接单。2核4GB建议并发1。并发修改需服务空闲；队列上限统计排队+运行总量，且扣除并发槽位。同视频重复提交复用进行中任务。当前单进程；不要用多个Uvicorn进程绕过容量控制。素材自动清理、每用户限额、持久工作队列与账户隔离仍未上线，公开发布前需要补齐。
