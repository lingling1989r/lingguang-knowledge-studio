# 开源、私有交付与商业化调研

日期：2026-10-13；调研结论与待开发方案，不是已经上线的产品。MCC按MCP理解；若指其他服务需另确认。

## 推荐

开源本机核心 + 本机MCP + 浏览器入口 + 可选轻量控制面。下载、转录、媒体存储在用户电脑/私有服务器；用户自带Agent/API凭据与飞书授权。我们收费提供安装维护、工作流、团队治理、可选元数据同步。MCP只是协议：远程MCP若仍由我们转录，成本并不会下降。

短期先交付可运行源码与安装服务，验证付费；之后打包桌面程序再补插件与本机MCP。当前代码只有本机网页与后端，以上包装尚未实现。用户网页和RSS收集可先使用现有入口。

## 方案比较

|方案|重处理归属|手机体验|商业化|主要风险|
|---|---|---|---|---|
|本机工作台/桌面应用|用户电脑|手机可发链接到轻量云队列，电脑上线后处理|年度维护、安装包、高级工作流|电脑休眠/离线与用户设备差异|
|浏览器插件+本机程序|用户电脑|移动端弱|便利性订阅、模板/维护|不能只靠插件保证长视频转录，需本机桥接|
|本机MCP|用户Agent设备|取决于Agent客户端|安装支持、工具集、团队版|Agent用户有限，需控制权限与凭据|
|私有部署+远程MCP|用户自己的服务器|可通过用户飞书机器人收集|部署费、升级维护、定制集成|客户承担算力/云费，运维服务不能无限承诺|
|混合云控制面|用户Worker做转录，平台只调度|手机发链接便利|账号/设备同步与团队治理订阅|离线延迟，仍有数据库/消息服务与授权运维费|
|全托管MCP/SaaS|我们服务器|方便|按音频分钟收费|并未解决平台算力压力，不作为首发|

## 多租户授权

用户登录产品账号，绑定自己的处理设备或私有Worker，再授权目标飞书空间与自己的模型服务。平台账号、飞书租户/用户和设备身份分别建模。各用户任务隔离，不能复用全站飞书Secret或一个公共登录会话。每个设备轮询自己的队列，发送签名状态、通过短期凭据取得任务；允许撤销设备。MCP工具读写必须过滤用户归属，源内容只作为数据。

本机密钥优先系统凭据库；纯私有部署由客户管理Secret。轻量云默认只收链接、状态与必要索引元数据，不收原媒体；若启用云端语义检索或远端LLM，正文/选定片段会离开设备，需清晰显示发送范围。链接本身也可能敏感。飞书机器人需要公网事件接入，不能直接访问休眠用户的localhost；云端排队或用户自己的公网网关是必需边界。

手机收集→链接队列→用户电脑上线→下载/转录→用户API整理→飞书→手机查看。状态应明确“等待你的设备上线”，不可承诺设备离线也即时完成。RSS订阅也要区分云端检测新集与本机实际处理。

## 建议试售产品

1. 开源社区：代码免费、自己安装、BYOK，无承诺响应时间。MIT允许商业使用，不能要求“商用必买许可证”。
2. 个人便利版：199–399元/年假设价。收费价值是签名安装包、自动更新、工作流维护、可选同步服务和有限支持；不包含无限模型/转录费。完整开源后技术用户可自行构建，不能靠隐藏开源核心收费。
3. 安装服务：299–999元/次假设价，写清系统范围、一次远程安装、验证与短期保障；后续运维另计。
4. 团队私有交付：3000–10000元基础实施假设价，年维护按明确工时/SLA另报，客户支付服务器、模型和飞书许可。先按工时报价，复杂OAuth/SSO/审计与迁移不能包含在低价固定包。
5. 混合云轻量订阅：99–299元/年假设价，仅队列/设备绑定/跨端状态与有限同步；媒体不经过平台。必须先测数据库、客服、账号与同步成本，不能宣称平台零成本。
6. 企业治理模块：审批、审计、权限策略、组织词表、批量数据源、定制Agent/知识库集成，可独立服务或可选模块收费，底层开源代码保持可用。

不推荐首发“远程MCP无限转录套餐”、低价终身客服或免费保存原视频。收费应按服务/可靠性/治理，非按接口名换包装。

## 成本归属与利润

用户自付设备电力、模型调用、可选ASR云费及自己的存储；平台承担安装打包、签名/更新、授权中继、订阅管理、客服与维护。手机体验依赖轻量云或用户自托管公网服务。

个人版试算（全是假设）：299元/年；每用户年度消息/状态同步5–20元、支付/税费按实际、客服20–100元，扣完后再分摊研发、签名证书、测试设备与固定服务器。不能只用每次模型费计算毛利。上门/远程安装1小时以上的服务必须按人工成本校准。

私有实施报价 = 预计工时×交付小时成本 + 风险储备 + 明确维护预算，不能把一套3000元套餐泛化到所有客户。

## 开源范围和权益

当前发布的是清理后的完整应用及网站代码，MIT；字体保留OFL。不包含个人QR、第三方示例视频截图、私有资料、登录、凭据或历史任务。用新的Git初始提交发布，旧开发历史不上网。README清晰列出实际能力与未实现能力。

开源不是免费托管或免费模型，发布时不承诺多租户、跨企业飞书OAuth、MCP、COS或插件已经完成。后续高级服务与新模块可以收费，但MIT已发布版本不能追溯限制。用户数据导出与私有部署继续可用。

## 实施路线与验证

第一步：开源快照、依赖/许可、安装手册、已有测试；寻找5名自安装用户+3名付费安装用户。
第二步：打包Mac/Windows安装程序，设备资源检测、凭据库、故障日志脱敏。至少两种硬件跑30分钟视频与播客。
第三步：本机MCP工具submit_source/get_status/search_notes/export_note，调用主机任务系统而不阻塞模型会话；浏览器插件只发链接，Native Messaging主机拒绝任意命令。
第四步：轻量云与手机入口；付费条件是实际跨端体验顺畅、设备离线状态准确、消息可靠。
第五步：私有团队版交付，验证租户权限、SSO、备份恢复、断网与升级。
