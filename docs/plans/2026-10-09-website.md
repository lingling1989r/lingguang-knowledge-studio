# B站视频到飞书图文网站

目标：输入B站视频URL，提取内容，生成原创公众号稿与配图，保存到飞书文档。

已确认的内容要求：靠谱公众号文风；开头知识图谱；毛笔SVG小标题；原视频截图；真实联系卡；文末来源链接。

界面：中文内容工作台，链接输入、可选图文素材、任务进度、历史稿件、文章预览、飞书链接和下载。

实现顺序：
1. 独立的前端界面及真实示例。
2. 受约束的B站地址解析、持久化任务状态及内容处理服务。
3. AI文章结构输出、SVG/PNG配图、飞书图文写入。
4. 输入验证、任务失败恢复、API与实际视频链路测试。

后台部署方式等待使用范围确认；普通静态托管不能运行视频下载、ffmpeg与本机语音识别。

安全与边界：凭据只在服务端；任务文件与账号配置不进入Git；只下载识别后的单个B站视频，不处理任意URL。输出原创摘要与文章，不提供第三方视频的全文逐字转载。
