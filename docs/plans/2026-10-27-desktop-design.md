# 桌面本机处理设计

目标由用户明确：尽量使用用户自己的设备；将OpenClacky CLI打包为Agent。选择原生WebView加受控本机Python子进程，复用现有工作台；相比Electron避免另打包浏览器，相比完整Tauri重写减少迁移。代价是Python、ML与Ruby依赖包仍较大，需平台分别构建。

下载、识别、图片和历史在用户设备；外部模型仅接收写作材料；飞书可选。用应用数据目录保存，随机loopback端口，实例文件锁，退出确认并停止进程组，重启标记中断任务可重试。

内置固定OpenClacky1.5.3与Ruby，不复用或复制开发者的Clacky配置。适配器临时HOME、关闭遥测、stdin传凭据、输出NDJSON提取最终JSON，后续沿用现有Article校验。非交互CLI原本自动批准，写稿入口关闭工具定义与查找；不是完整OS沙箱。

默认并发1，保持磁盘余量要求；无中央存储或公开用户并发。商业化与多租户不在本批添加。正式分发仍需签名、干净设备测试与依赖合规审核。
